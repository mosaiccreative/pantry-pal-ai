# pantry-pal-ai — Food AI Assistant

## What This Is
An AI-powered assistant for recipe suggestions and pantry management.

## Priorities
- Good UX for adding/managing pantry items
- AI recipe suggestions that actually make sense
- Handle dietary restrictions and allergies (important for user trust)
- Mobile-friendly (people use this in the kitchen)

## Note on Allergies
- While this is low-risk overall, if you add allergy/dietary filtering, test that thoroughly — incorrect allergy info is a safety issue.
